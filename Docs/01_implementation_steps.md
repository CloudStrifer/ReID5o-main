# 顺序实施与验收

1. **数据基础**：按明确 split 字段/划分清单读数据；没有 CUHK split 就给出可操作错误；图像来源目录不充当训练/测试划分。素描按相对路径 stem 匹配，重复或缺失报错。训练输出 `[B,5]` 可用性，三模态数据的 NIR/CP 不读取 RGB 占位。
2. **端到端方法**：用真实可用输入提取监督目标；按样本采样缺失状态；MRE 构造所有有效数据集模态的状态特征；CMC 只用观测上下文补全；RAF 融合真实与生成特征；同一最终表示用于 ID、SDM、一致性。结构上不存在的模态不参与三模态数据的生成监督。
3. **SPA-LoRA**：冻结基础视觉权重，在后若干 Transformer 层的 MLP 插入状态路由适配器。视觉 patch 按高度划成 P 个部位；CLS 使用各部位增量均值；每部位独立 E 个低秩专家，路由为 `softmax(W_p v)`。检查状态变化、空间分块与反向梯度。
4. **统一检索协议**：实现公共 `encode_multimodal`；训练、测试、展示调用它。评估按固定 seed、样本索引生成缺失 mask，导出 JSON；主表分别写明训练 dropout 和测试 missing rate。保持样本有效，单模态输入被保留；报告请求删除率和实际删除率。
5. **复现实验基础**：参数支持 `--no-*`，保存类别数和架构版本；统一模型精度与设备；无验证集时选固定最后一轮，不拿测试集挑 best；有验证集时检查训练/验证身份隔离。提供实验配置、消融/缺失率入口和统计导出。
6. **验证与论文更新**：先用小型骨干和合成张量做功能/梯度测试，再从现有 ZIP 临时读取少量真实数据核验加载；无需完整解压。真实 CLIP/完整数据训练、全量指标、效率与图表列为独立实验验收。

每一步分别记录实现、忠实度审定与实验验收，不能因功能测试通过就标记论文全部完成。[07 忠实度再核查](07_fidelity_reaudit.md) 记录本次发现的遗漏和仍需核实的实现选择。任何正式划分文件、历史实验结果缺失均如实记录，不能从现有数值反推配置。
