# 再核查：实现、论文忠实度与实验复现

当前结论：核心模块已有一版可执行实现，不能称为“论文全部补齐”。之前 README 的“实现完成”标记过宽，现已收紧。文件数量、代码行数和测试数量都不能作为论文忠实度的验收依据。

## 这次复查发现并修正的遗漏

1. **训练数据随机配对被简化**：重写读取器时，三模态数据只保留首条 caption，ORBench 同身份的辅助图像也没有按轮重新采样。现保留原 caption 候选和同身份模态池，并在每轮训练开始时重新采样；不修改原始记录。
2. **重建损失的 batch 分母不一致**：之前只平均存在重建目标的样本。现先在每个样本内部平均被遮挡目标，再平均整个 batch；空目标集合明确约定贡献零。论文式 (10) 没有定义空集合，这个边界约定仍需在方法文字中说明。
3. **循环损失的采样和平均不一致**：之前使用全 batch 的公共模态对并按模态对平均，无法对应论文式 (11) 的每样本集合 P_i。现按样本抽取模态对，先平均该样本的循环损失，再平均整个 batch；空集合贡献零。

新增独立数值测试分别核对不同目标数、不同循环对数和空集合的结果，并检查随机采样的可重复性及训练器调用。当前共 32 项测试通过，耗时 36.15 秒；这只证明这些被检查的行为。

## 尚不能当作“与原论文完全一致”的实现选择

论文未完整限定的细节必须明确记录；以下不是已经恢复的历史实验配置，也不能仅凭功能测试确认。

| 项目 | 当前选择及待核实事项 |
|---|---|
| SPA 插入位置 | 视觉 Transformer 后两层 MLP 的 c_fc/c_proj；论文未给出足够细节来证明这是原设置 |
| 空间区域与 CLS | 水平 patch 条带；CLS 使用部位增量均值；增量缩放为 1/r。需要与方法描述及实际参数实验一致 |
| E/P 默认值 | 当前 E=4/P=3；论文实验设置写 E=3/P=4，敏感性分析又给出 E=4/P=3。不能同时声称两套都是同一默认 |
| 缺失查询 | learnable query 加 pooled MRE missing sequence；这是使缺失先验接入主检索梯度的具体选择，论文只描述语义查询 |
| 完整监督分支 | 使用停梯度的完整分支；论文未明确 teacher 是否停梯度，训练时 dropout 也会影响目标特征 |
| 人工遮挡 | 当前 Bernoulli 采样可以保留全部模态；warmup 也可不遮挡。论文文字说遮挡一个或多个模态，空目标约定及 warmup 需要交代或进一步改为强制非空遮挡 |
| 循环对范围 | 每样本默认最多 3 对，当前要求 a、b 都真实可用。论文仅明确源 a 可观测；是否允许 b 为天然缺失模态、是否遍历全部对，仍需核实 |
| ID/SDM 训练定义 | 当前为一个随机缺失 query 与 RGB gallery 的最终融合表示；替换了旧实现的 16 组合损失。该改动不是等价修补，不能据此宣称保留原训练行为 |
| 测试缺失率 | 当前为带非空修复的 Bernoulli 删除；实际比例不一定等于请求比例，单 RGB gallery 实际删除率为零。这是新定义协议，未恢复历史主表协议 |
| 冻结与精度 | 默认冻结视觉基础权重、训练文本分支；默认 FP32，可开启 AMP。完整预训练模型上的设置与研究用硬件表现尚未验证 |

涉及上述选择的论文修改应写成“当前实现的说明或候选修订”，不能通过改写论文来声称已复现原方法。

5. 八种外部比较方法的代码、权重及统一协议结果未在当前工程提供，也未由本轮实现或运行。
6. 从正式 checkpoint 重新生成可靠性权重表、检索图、t-SNE、真实/生成特征图及效率数据；已有图表不能视为新代码的证据。
