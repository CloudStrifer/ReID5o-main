# MFCRAF 论文与代码对齐

**验收结论修正：目前是核心模块的候选实现与功能测试，不能称为论文全部补齐。** 复查发现的遗漏、实现假设与未完成项见 [07 忠实度再核查](07_fidelity_reaudit.md)。

按下列顺序执行，每一步记录实现、验证和剩余限制。原实现备份位于 `output/pre_alignment_backup/`；前期问题清单位于 `output/audit/paper_code_alignment_zh.md`。

| 步骤 | 内容 | 验收条件 | 状态 |
|---|---|---|---|
| 01 | 数据划分、素描配对、逐样本有效模态 | 不用 RGB 冒充 SK/NIR/CP；正式 split；采样后至少一个观测 | 读取保护与随机采样已实现；全量验收及 CUHK 正式划分待补 |
| 02 | MRE、真实目标监督、CMC、RAF 与检索损失接通 | 补全器和可靠性融合能从检索损失收到梯度；核对公式与训练定义 | 核心路径可执行；损失平均已修正；训练定义仍需核实 |
| 03 | SPA-LoRA | P 个水平空间部位、每部位 E 个专家、由逐样本缺失向量路由 | 候选实现；层位置、CLS 和 E/P 设定待核实 |
| 04 | 统一训练、评估、展示与确定性缺失协议 | query/gallery 使用相同编码接口；导出固定 mask；无静默降级 | 统一入口可执行；新协议不能视为历史协议 |
| 05 | 配置、模型选择、复现工具 | 30 epochs、默认 LoRA/mAP、可关闭消融、独立验证、日志与权重可追溯 | 工具可用；正式运行及结果未完成 |
| 06 | 自动验证与论文修改清单 | CPU 前向/反向、梯度、状态路由、数据与协议测试；列明必须重跑的实验 | 小规模功能测试通过；不代表论文忠实度或复现完成 |

实施约定：代码以论文公式为参考，并包含未被论文完整限定的实现选择。论文 E/P 前后冲突，暂以分析部分及图 9 的 E=4、P=3 为默认，并通过参数支持其他值。测试缺失协议尚缺正式定义，采用并明确记录“逐样本独立 Bernoulli 删除后保留至少一个原有模态”，不把它冒称为历史表格所用协议。只有 RGB 的 gallery 无法同时删除 RGB 又保留有效观测，其有效删除率必然为零；多模态 gallery 可通过统一接口提供。

代码完成与实验结论分开验收：不修改或编造论文已有数值。改变方法后，表格、消融、可靠性权重、检索图和 t-SNE 均需重新生成。
