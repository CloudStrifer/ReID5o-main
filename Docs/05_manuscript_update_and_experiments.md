## 方法描述

- §3.2：统一 E=4、P=3 作为当前默认；SPA 插入共享视觉 Transformer 后两层 MLP 的 c_fc/c_proj；水平 patch 条带、CLS 采用部位增量均值。其他设置由参数实验决定，不能同时声称 E=3/P=4 是同一默认。
- §3.3：写明逐样本 [B,K] dropout，先限制真实模态、再修复非空；MRE 缺失序列池化先验组成模态专属查询。完整分支作为停梯度监督，一致性为 cosine discrepancy，没有对比温度。
- §3.4：上下文仅包含观测模态；监督目标取遮挡前真实特征，天然缺失模态没有重建目标；当前每样本随机抽最多三个有效有向 cycle 对。生成结果参与主检索损失。两项损失先在样本内平均，再平均整个 batch；空集合的零贡献约定需要交代。
- §3.5：两层 MLP、固定 fusion temperature、一层置信度投影；真实/生成标志按样本记录；最终表示确实为 Proj(sum(w*u))，无额外未加权 Transformer。质量特征采用归一化方差、原始 L2 norm、sigmoid confidence。
- §3.6：明确 ID 在 query 与 RGB-gallery 最终表示上的平均、SDM 在二者之间计算；auxiliary warmup、teacher 停梯度也应交代。
- §4.1：采用新协议必须写出 Bernoulli 删除和非空修复，报告实际删除率。单 RGB gallery 无法验证 gallery 删除；多模态 gallery 必须真实提供。
- §4.2：30 epochs、batch=8、r=4、E=4/P=3、五项权重与代码默认一致。Adam eps=1e-3 为当前继承设置；bias 2 倍、LoRA/router 5 倍学习率，bias 优先。不要把默认和实际命令混写。

## 必须重做或核实的结果

1. 所有受新方法、正式 split 或新协议影响的主表：四数据集 × 四缺失率；补充主 query 任务和 seeds。
2. MA/CC/RF 模块消融、无 SPA、无 MA、两个补全损失的独立及联合消融。
3. consistency、completion、fusion 权重敏感性；E/P、RGB keep probability 实验。
4. 重新导出完整五模态可靠性权重；如果论文只画四种辅助模态，必须说明额外归一化，不能套用五模态原始权重。
5. 检索图、t-SNE 和真实/生成特征图必须由同一 encoder 和对应 checkpoint 导出。
6. 推理耗时、参数量、显存及 RTX-3090 可运行性须在研究用硬件测量；CPU 夹具测试不能支撑这些结论。
7. 八种对比方法的实际代码、权重和结果未在当前工程提供。它们需要独立复现并复用同一正式数据划分及缺失 mask；本轮没有实现或运行这些外部方法，不能保留“已公平复现”的结论而没有记录。

- CUHK caption_all.json 没有正式 split，当前仍需正式划分清单。读取器现会明确报错，避免继续产生非正式划分指标。
